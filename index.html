    About the Project

    Library Book Finder helps students locate books without wandering the stacks. A QR code displayed in the library opens this site; a search then returns the floor, section, rack and shelf.

    Built with

    • HTML5, CSS3 and vanilla JavaScript. No framework and no backend.
    • jsQR (via jsDelivr CDN) reads QR codes from the camera.
    • qrcodejs (via cdnjs CDN) generates QR codes.
    • Book records live in js/books.js; admin edits are saved in localStorage.

    Limits of this demo

    There is no secure authentication and no shared database. Admin changes stay in one browser. To publish changes for everyone, edit js/books.js (or import an exported JSON file into the default list) and push to GitHub.
